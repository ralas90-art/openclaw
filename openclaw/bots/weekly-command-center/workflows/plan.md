# Workflow: /weekly plan

## Description
Establishes the weekly growth focus areas, targets KPIs, and details task assignments with owners.

## Inputs required from User
- Primary Target KPI (e.g. Increase demo shows)
- Team Member Names & Roles
- Expected Deliverables

## Execution Steps
1. **Focus Mapping**: Select the top 1-3 objectives based on the bottlenecks identified in the review.
2. **Execution Checklist**: Break objectives into specific tasks assigned to owners with deadlines.
3. **Invoke Skill**: `weekly-command-center` -> Formulate the execution plan.
4. **Output**: Generate `weekly-execution-plan.md` under `/openclaw/reports/weekly-summaries/`.
5. **Checkpoint**: Pause for task lists and priorities alignment.
