# Workflow: /revenue offer-design

## Description
Develops high-converting pricing offers and value-stacked packaging templates (Hormozi-style).

## Inputs required from User
- Brand Name
- Core Product/Service
- Current Pricing Structure
- Primary Competitors
- Key Customer Objections

## Execution Steps
1. **ICP Alignment**: Audit customer pain points to shape the offer benefits.
2. **Value Stacking**: Formulate bonuses, speed/convenience assets, guarantees, and risk-reversal structures.
3. **Packaging**: Formulate tiered pricing sheets (Core, Premium, Enterprise).
4. **Invoke Skill**: `offer-engine-builder` -> Generate the detailed offer design.
5. **Output**: Generate `offer-design.md` under `/campaigns/{brand}/revenue-strategy/`.
6. **Checkpoint**: Pause for user pricing sign-off.
